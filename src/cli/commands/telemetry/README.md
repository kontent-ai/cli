# `kontent telemetry`

<!-- reference:start -->
## `kontent telemetry status`

Show whether telemetry is enabled and why

### Usage

```sh
kontent telemetry status
```

## `kontent telemetry enable`

Enable anonymous usage telemetry

### Usage

```sh
kontent telemetry enable
```

## `kontent telemetry disable`

Disable anonymous usage telemetry

### Usage

```sh
kontent telemetry disable
```
