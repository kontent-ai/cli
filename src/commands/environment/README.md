# `kontent environment`

<!-- reference:start -->
## `kontent environment use <envId>`

Set the default environment used when --envId is omitted

### Usage

```sh
kontent environment use <envId>
```

### Arguments

| Argument | Type | Description |
| --- | --- | --- |
| `<envId>` | string | Environment ID (Guid) |

## `kontent environment current`

Print the default environment ID

### Usage

```sh
kontent environment current
```

## `kontent environment clear`

Remove the default environment, making --envId required again

### Usage

```sh
kontent environment clear
```
